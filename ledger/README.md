# Ledger

A local-first stock trading journal. Trades, notes, and stats stay in this browser unless you export a backup.

This is a standalone app. It is not part of KJV Study.

## Run

```bash
cd ledger
npm install
npm run dev
```

## Features

- Log long/short trades with size, entry/exit, fees, stop, target, setup, tags, and grade
- Review notes: thesis, emotion, mistakes, lessons
- Dashboard: realized P&L, equity curve, win rate, profit factor, expectancy, average R, max drawdown
- Analytics by symbol, setup, grade, side, and weekday
- JSON/CSV backup and a demo journal

## Build

```bash
npm run build
npm run preview
```
